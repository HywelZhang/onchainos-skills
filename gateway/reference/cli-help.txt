# onchainos CLI 参数面（自动抓取，用于 gateway 委托层实现）

## onchainos agent create-task
```
Create a new task (Client)

Usage: onchainos.EXE agent create-task [OPTIONS] --description <DESCRIPTION> --budget <BUDGET> --max-budget <MAX_BUDGET> --currency <CURRENCY> --provider <PROVIDER> --payment-mode <PAYMENT_MODE> --service-id <SERVICE_ID>

Options:
      --base-url <BASE_URL>
          Backend service URL (overrides config)
      --description <DESCRIPTION>
          
      --budget <BUDGET>
          
      --chain <CHAIN>
          Chain: ethereum, solana, base, bsc, polygon, arbitrum, sui, etc
      --max-budget <MAX_BUDGET>
          
      --currency <CURRENCY>
          
      --title <TITLE>
          
      --provider <PROVIDER>
          Specified provider agentId (required; skip asp-match, negotiate directly with this provider or x402 accept)
      --endpoint <ENDPOINT>
          Designated service endpoint (persisted for multi-service providers)
      --file <ATTACHMENTS>
          Local file paths to attach to the task after creation
      --payment-mode <PAYMENT_MODE>
          Payment mode to set at creation time (required; escrow / x402)
      --service-id <SERVICE_ID>
          Service ID from asp/match response (required)
      --service-params <SERVICE_PARAMS>
          Service input parameters (natural language string)
      --service-token-address <SERVICE_TOKEN_ADDRESS>
          Service token contract address
      --service-token-amount <SERVICE_TOKEN_AMOUNT>
          Service price (from asp/match feeAmount)
  -h, --help
          Print help
```

## onchainos agent create-subscribe
```
Create a subscription task

Usage: onchainos.EXE agent create-subscribe [OPTIONS] --service-id <SERVICE_ID> --service-token-amount <SERVICE_TOKEN_AMOUNT> --service-token-address <SERVICE_TOKEN_ADDRESS> --auto-renew <AUTO_RENEW> --title <TITLE> --description <DESCRIPTION>

Options:
      --base-url <BASE_URL>
          Backend service URL (overrides config)
      --service-id <SERVICE_ID>
          
      --chain <CHAIN>
          Chain: ethereum, solana, base, bsc, polygon, arbitrum, sui, etc
      --use-trial <USE_TRIAL>
          [default: false] [possible values: true, false]
      --service-params <SERVICE_PARAMS>
          [default: ""]
      --service-token-amount <SERVICE_TOKEN_AMOUNT>
          
      --service-token-address <SERVICE_TOKEN_ADDRESS>
          
      --auto-renew <AUTO_RENEW>
          
      --title <TITLE>
          
      --description <DESCRIPTION>
          
      --provider-agent-id <PROVIDER_AGENT_ID>
          
      --service-description <SERVICE_DESCRIPTION>
          Exact service description returned by asp-match. Only bounded asset/tool hints are persisted; the raw prose is never executed [default: ""]
      --service-interval <SERVICE_INTERVAL>
          [default: month]
      --autotrade-mode <AUTOTRADE_MODE>
          Explicit user-confirmed automatic signal execution (`auto`)
      --autotrade-amount <AUTOTRADE_AMOUNT>
          Fixed quote amount used for every delivered signal. [UNIT: human-readable decimal selected by --autotrade-quote; number only, e.g. 20.5; never minimal units; do not include a USDT/USDC suffix.]
      --autotrade-cap <AUTOTRADE_CAP>
          Per-delivery automatic-execution quote cap. [UNIT: human-readable decimal selected by --autotrade-quote; number only, e.g. 50; never minimal units; do not include a USDT/USDC suffix.]
      --autotrade-quote <AUTOTRADE_QUOTE>
          Quote currency for amount/cap (`usdt` or `usdc`)
      --autotrade-environment <AUTOTRADE_ENVIRONMENT>
          User-authorized Trade Kit environment (`live` or `demo`)
      --autotrade-margin-mode <AUTOTRADE_MARGIN_MODE>
          User-authorized Trade Kit derivative margin mode
      --autotrade-order-policy <AUTOTRADE_ORDER_POLICY>
          User-authorized signal-entry order policy
      --format <FORMAT>
          [default: ""]
  -h, --help
          Print help
```

## onchainos agent subscribe-device-update
```
Overwrite the receive-device list for one or more subscriptions (batch). The passed list wholly replaces the stored list; empty/omitted clears it

Usage: onchainos.EXE agent subscribe-device-update [OPTIONS]

Options:
      --base-url <BASE_URL>        Backend service URL (overrides config)
      --job-id <JOB_ID>            Subscription jobId to overwrite (Form A, single subscription)
      --chain <CHAIN>              Chain: ethereum, solana, base, bsc, polygon, arbitrum, sui, etc
      --device-list <DEVICE_LIST>  Comma-separated device ids (Form A); empty/omitted clears the list
      --items <ITEMS>              JSON array of {jobId, deviceList} (Form B, batch). Mutually exclusive with --job-id/--device-list
  -h, --help                       Print help
```

```
Usage: onchainos.EXE agent apply [OPTIONS] --token-amount <TOKEN_AMOUNT> --token-symbol <TOKEN_SYMBOL> --agent-id <AGENT_ID> <JOB_ID>

Arguments:
  <JOB_ID>  

Options:
      --base-url <BASE_URL>          Backend service URL (overrides config)
      --token-amount <TOKEN_AMOUNT>  Negotiated token amount. **Required**; must be > 0 (empty / 0 = apply for free, irreversible — CLI rejects)
      --chain <CHAIN>                Chain: ethereum, solana, base, bsc, polygon, arbitrum, sui, etc
      --token-symbol <TOKEN_SYMBOL>  Actual task currency (USDT / USDG); read from negotiation context, do not assume USDT
      --agent-id <AGENT_ID>          
  -h, --help                         Print help
```

## onchainos agent deliver
```
Provider submits deliverable (submit API → sign → broadcast)

Usage: onchainos.EXE agent deliver [OPTIONS] --agent-id <AGENT_ID> <JOB_ID>

Arguments:
  <JOB_ID>  

Options:
      --base-url <BASE_URL>
          Backend service URL (overrides config)
      --file <FILE>
          [default: ""]
      --chain <CHAIN>
          Chain: ethereum, solana, base, bsc, polygon, arbitrum, sui, etc
      --message <MESSAGE>
          [default: "Task completed, please review"]
      --deliverable-text <DELIVERABLE_TEXT>
          Text deliverable content for auto-save. When non-empty and --file is empty, the CLI writes this to a temp file and persists it as a text deliverable [default: ""]
      --agent-id <AGENT_ID>
          Provider agentId (required). Beta backend rejects empty agenticId header → 3001 auth fail
      --autotrade <AUTOTRADE>
          Deprecated compatibility argument. Accepted but ignored; only the explicit text/file deliverable is sent and processed [default: ""]
  -h, --help
          Print help
```
